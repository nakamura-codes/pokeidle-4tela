# PokeIdle (4 contas)
App Android que mantém o pokeidle.io rodando em segundo plano, com até 4 contas em abas.

# Instruções de uso
1. Baixe o APK.
2. Instale o APK no celular (permita "fontes desconhecidas").
3. Ao abrir: aceite notificações e a isenção de bateria.
4. Faça login com uma conta ou duas.
5. Divirta-se com seu farm idle no telefone em segundo plano.
