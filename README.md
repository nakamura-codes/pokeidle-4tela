# PokeIdle (2 contas)
App Android que mantém o pokeidle.io rodando em segundo plano, com até 2 contas em abas.

# Instruções de uso
1. Baixe o APK.
2. Instale o APK.
3. Aceita notificações e coloque isenção de bateria
4. Logue com uma conta ou duas.
5. Divirta-se com seu farm idle no telefone em segundo plano.
